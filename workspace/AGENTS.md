# AGENTS.md
# このファイルはClaude CodeやGooseなどのAIエージェントに対する作業ルール・指示を定義します。

## プロジェクト概要
- 本プロジェクトは、AIエージェントの安全な隔離環境（サンドボックス）を提供するワークスペースです。

## コーディング・作業ルール
1. **言語設定**: 全ての応答・コードコメント・コミットメッセージ・ドキュメントは日本語を使用してください。
2. **変更の検証**: コードや設定を変更した後は、必ず検証コマンドを実行して正常動作を確認してください。
3. **外部通信の注意**: 本サンドボックス内ではプロキシでホワイトリスト化されていないドメインへの通信は遮断されます。許可されているドメインとのみやり取りを行ってください。
4. **秘密情報の取り扱い**: ホストから同期されるファイルの中で、`.env` ファイルや `.ssh` などの秘密情報が含まれるファイルは操作しないでください。秘密情報をログに出力したり、新たに生成したりすることも禁止します。
5. **Git操作の制限**: リモートリポジトリへの `git push` などの書き込み操作は制限されています。必要最小限のローカルコミットのみを行ってください。
