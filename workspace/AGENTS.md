# AGENTS.md
# このファイルはClaude CodeやGooseなどのAIエージェントに対する作業ルール・指示を定義します。

## プロジェクト概要
- 本プロジェクトは、AIエージェントの安全な隔離環境（サンドボックス）を提供するワークスペースです。

## コーディング・作業ルール
1. **言語設定**: 全ての応答・コードコメント・コミットメッセージ・ドキュメントは日本語を使用してください。
2. **変更の検証**: コードや設定を変更した後は、必ず検証コマンドを実行して正常動作を確認してください。
3. **外部通信の注意**: 本サンドボックス内ではプロキシでホワイトリスト化されていないドメインへの通信は遮断されます。
