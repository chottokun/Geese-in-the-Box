# セキュリティおよび通信ルール

1. **プロキシ外部通信の原則**: 本環境は Squid プロキシによって許可ドメイン以外への通信が遮断されています。外部通信エラーが発生した場合は、プロキシのホワイトリスト（`squid/whitelist.txt`）を確認してください。許可されていないドメインへのアクセスを回避するための手段を講じないでください。
2. **シークレット情報の保護**: APIキー、トークン、パスワード、秘密鍵などの秘密情報をファイル内やログに平文で書き込まないでください。ホストの機密情報（`.env` や `.git` の認証情報）へのアクセスは禁止されています。
3. **Git操作の制限**: リモートリポジトリに対する `git push` や、ホストの認証情報を利用したリモート操作を禁止します。ローカルでのコミット操作のみを許可します。
4. **悪意のある行動の禁止**: サンドボックスの隔離環境を突破しようとする試みや、システムへの不正なコマンド実行（シェルインジェクションなど）は固く禁止されています。
